API Endpoints

  • GET /health — Health check.
  • GET /model-info — Model metadata.
  • POST /predict — Predict single transaction. Expects JSON {"features": [30 numbers], "threshold": 0.5}
  • POST /predict-batch — Predict multiple transactions. Expects JSON {"transactions": [[...],[...]], "threshold": 0.5}

From GitHub Pages you may need to provide the API URL (host and port) if the API runs separately.
