About This Project

Project Summary

The Credit Card Fraud Detection project provides a full example pipeline for detecting fraudulent credit card transactions. It includes data ingestion and preprocessing, model training, evaluation, and a RESTful API to serve predictions.

Key Features

  • Robust data preprocessing and outlier handling
  • Class imbalance treatment with SMOTE + undersampling
  • Model training and persistence (XGBoost by default)
  • Flask-based API for single and batch predictions
  • Optional Docker support for containerized deployment

How to Use

See the Documentation for setup and run instructions. Use Detect to try a quick demo from the browser.
