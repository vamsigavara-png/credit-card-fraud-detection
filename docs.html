Documentation

Overview

This documentation covers prerequisites, installation, training, running the API, and troubleshooting guidance for the project.

Prerequisites

  • Python 3.8+ (3.10 recommended)
  • pip and virtualenv
  • Optional: Docker and Docker Compose for containerized runs

Quick Setup

python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\Activate
pip install -r requirements.txt

Training the Model

Train the model and create persistent artifacts (model + scaler):

python main.py --mode train
# Artifacts are saved to the models/ directory by default

Run the API Locally

Start the Flask API (loads saved model artifacts):

python -m api.app
# Default: listens on http://0.0.0.0:5000

API Usage Examples

Health check:

curl http://localhost:5000/health

Single transaction prediction (example with demo features):

curl -X POST http://localhost:5000/predict \
  -H "Content-Type: application/json" \
  -d '{"features": [0,0, ..., 123.45]}'

Troubleshooting

  • If the API reports Model not loaded, ensure the files models/xgb_model.pkl and models/scaler.pkl exist.
  • Check that dependencies from requirements.txt are installed and compatible.
  • To inspect logs, run the API from a terminal and watch startup messages; the app logs model-loading errors to stdout.
  • If using Docker, ensure Docker Desktop is running and then: docker-compose up --build.

Deployment

GitHub Actions are included for Pages/Jekyll and Docker CI. For production API deployments, use a WSGI server (Gunicorn) or a container orchestration platform.
