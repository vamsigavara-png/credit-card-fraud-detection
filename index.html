Credit Card Fraud Detection

Machine learning model and API for detecting fraudulent credit card transactions.

What this project includes

Data pipeline

Loads and preprocesses credit card transaction data, handles outliers, scaling, and class imbalance.

Model training

Trains a fraud detection model using the cleaned dataset and saves the trained artifacts.

API deployment

Serves predictions through a Flask REST API for realtime fraud scoring.

Visit the repository on GitHub for details, or run the project locally with Python and Docker.
